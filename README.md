# 🐍 Python PCEP Certification Mastery

Este repositorio contiene mi progreso y ejercicios prácticos para la certificación **PCEP – Certified Entry-Level Python Programmer**.

## 📑 Estructura del Repositorio
El código está organizado por ramas para separar cada bloque de conocimiento evaluado en el examen oficial:

- **Módulo 1:** Fundamentos (Tipos de datos, variables, operadores).
- **Módulo 2:** Control de Flujo (Lógica booleana, bucles y listas).
- **Módulo 3:** Colecciones (Tuplas y diccionarios).
- **Módulo 4:** Funciones y Excepciones.

## 🛠️ Tecnologías Utilizadas
- Python 3.x
- Git (Branching strategy)
- Bibliotecas estándar de Python
